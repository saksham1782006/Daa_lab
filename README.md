## About This Repository

This repository contains the **12 practical experiments** prescribed for the **Design and Analysis of Algorithms (DAA)** lab.

## Experiment Index

| Experiment | Name | Main Concept |
|:--:|---|---|
| **01** | Sorting Algorithms | Merge Sort, Quick Sort, Bubble Sort, Selection Sort and Heap Sort |
| **02** | Searching Algorithms | Linear Search and Binary Search |
| **03** | Strassen's Matrix Multiplication | Divide and Conquer |
| **04** | Huffman Coding | Greedy Algorithm |
| **05** | Minimum Spanning Tree (MST) | Prim's and Kruskal's Algorithms |
| **06** | Dijkstra's Algorithm | Single-Source Shortest Path |
| **07** | Bellman-Ford Algorithm | Shortest Path with Negative Edge Weights |
| **08** | N-Queens Problem | Backtracking |
| **09** | Longest Common Subsequence (LCS) | Dynamic Programming |
| **10** | String Matching Algorithms | Naive String Matching, Rabin-Karp and KMP |
| **11** | Floyd-Warshall Algorithm | All-Pairs Shortest Paths |
| **12** | 0/1 Knapsack Problem | Dynamic Programming |

---

Implement the 0/1 Knapsack problem using Dynamic Programming to maximise the total profit without exceeding the knapsack capacity.

</details>

By completing these experiments, i will practise:

- Divide and Conquer
- Greedy Algorithms
- Dynamic Programming
- Backtracking
- Graph Algorithms
- Searching and Sorting
- String Matching
- Asymptotic Time and Space Complexity
